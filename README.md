# Своя игра — Глобальная экономика

Статический сайт в формате «Своя игра»: 5 категорий × 5 вопросов, стоимость 100–500 баллов.

## Админ-доступ
Кнопка «Ответы» открывает форму пароля. После успешного ввода доступ сохраняется в localStorage на этом устройстве, поэтому повторно вводить пароль не нужно.

## GitHub Pages
Сайт автоматически публикуется через workflow `.github/workflows/pages.yml`.

> Важно: это клиентский статический сайт. Пароль и ответы не являются криптографически защищёнными и технически могут быть извлечены из исходного кода публичного репозитория.
