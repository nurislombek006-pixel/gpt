# Конструктор «Своя игра»

Веб-конструктор викторин с ручным вводом и генерацией через Cloudflare Workers AI.

**Онлайн:** https://svoya-game-ai-builder.masterofluck112-apps.workers.dev/

## Возможности
- 1–12 тем, 1–10 команд, до 120 вопросов.
- Автоматическое распределение при делимости числа вопросов на число тем.
- Подсказки ближайшего количества вопросов (например, 5 тем / 30 вопросов = по 6).
- Баллы автоматически: 100, 200, 300 … по каждому уровню.
- Генерация вопросов по названиям тем, описанию и тексту лекции через Workers AI.
- Редактирование каждого вопроса и ответа вручную.
- Экспорт автономного `index.html`, предпросмотр, резервная копия JSON.
- На игровой странице: команды, подсчет очков, минусовые баллы, отмена, сброс, пароль ответов.
- Локальное сохранение состояния в браузере.

## Архитектура
`index.html` — интерфейс конструктора; `builder.js` — редактор, управление настройками и экспорт; `game.html` — шаблон автономной игры; `worker.js` — облачный API и раздача статических файлов.

Облачный Worker подключен отдельно и публикуется на workers.dev. Для развёртывания на другом аккаунте Cloudflare необходимы bindings `AI` (Workers AI) и `QUIZ_LIMITER` (Rate Limiting) и корректный адрес Worker в конструкторе.

## Замечания
- Файл игры работает без интернета, но вызовы ИИ требуют опубликованного Cloudflare Worker.
- При превышении лимитов Workers AI или rate limiting генерация может быть недоступна; ручной режим остается доступным.
- Пароль находится внутри экспортируемого HTML и не является надёжной защитой секретной информации от технически подготовленных пользователей.
- ИИ может ошибаться. Проверьте факты до использования викторины.
