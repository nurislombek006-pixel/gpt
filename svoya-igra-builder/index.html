1. Параметры игры

Число вопросов должно делиться на число тем — тогда везде одинаковое количество уровней.

2. Темы и материал

Напиши названия категорий. Для ИИ можно добавить общий предмет, текст лекции или конспект.

Для PDF и PowerPoint можно скопировать текст слайдов в поле выше.

3. Создай вопросы

В каждом уровне — свой вопрос и правильный ответ. Ты можешь изменить любой ответ, даже после генерации ИИ.

⚙️ Настройки ИИ (Cloudflare Workers AI)

ИИ вызывается через отдельный Cloudflare Worker, а не напрямую из браузера. Для работы нужна опубликованная серверная функция. Если страница открыта на том же домене, оставь поле пустым; иначе укажи адрес Worker (например, https://...workers.dev).

Сам ключ не вводи. ИИ-запросы могут иметь ограничения по количеству, а при публикации публичного сервера — расходы по тарифу Cloudflare.

4. Готовая игра

В экспортируемый файл попадут выбранные темы, команды, вопросы, ответы, баллы и пароль. Никакого сервера для игры не требуется.

Конструктор «Своя игра» · Все настройки сохраняются в этом браузере · AI-ответы проверяй перед использованием.
